1.快捷键
	F12	呼出|隐藏辅助工具
	ALT+B	切换显示人名状态
	ALT+C	快速组队
	ALT+E	切换持续破盾状态/持续魔法盾/持续幽灵盾
	ALT+R	切换持续破击状态/持续风影盾/持续神圣战甲术
	ALT+M	切换持续金刚|护身
	ALT+F	切换瞬移抢物功能
	ALT+Y	添加黑名
	ALT+G   智能寻路开启/关闭
	ALT+D	切换物品名称显示方案(选择是否只显示极品名称)
	ALT+A	自动野蛮(突斩)/自动狮子吼/自动抗拒
	ALT+?	向队友发出PK呼救消息
	ALT+S	切换追杀模式
	ALT+Z：快速开启/关闭任务追踪信息
	ALT+1-7 切换攻击模式
	~	快速锁定|解除锁定
	INSERT	查看装备的持久度
	DELETE	查看BOSS死亡时刻，同时按下Home(End)，可以翻页
	TAB	切换持续魔法攻击状态
	PageUp  查看PK记录
	Ctrl+B  跑不停开启/关闭
	!       游戏中喊话
	!~      行会聊天
	$       宗族聊天
2.小技巧
	聊天栏里输入@find x y，会在全景小地图上显示这个点的位置
	聊天栏里输入@fly x y，会用瞬移技能飞到指定坐标
	聊天栏里输入@关闭辅助工具，会关闭辅助工具
	聊天栏里输入@开启辅助工具，可以打开辅助工具
	聊天栏里输入%姓名，可以直接加此人为黑名
3.你知道吗
	游戏中聊天频道按钮可以进行来言屏蔽，避免了在辅助工具上屏蔽的繁琐
